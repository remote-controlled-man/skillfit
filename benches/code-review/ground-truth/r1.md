## Scoring anchors

The bundled verifier (`verifiers/seeded-bugs.mjs`) collapses this rubric to four deterministic checks: one per seeded defect, each hit by a `file:line` or an unambiguous keyword reference on a line naming the file, plus `no-false-positives`, which fails when any decoy is reported. Exit code 0 requires all four, so the −1 penalty above is enforced rather than merely described.

`missing-tests` recognizes English and Chinese claims about absent or insufficient coverage, or required tests, on a line naming `applyBulkDiscount`. Merely naming tests or stating that coverage exists earns no credit. The verifier checks each finding on its own line; a valid coverage finding does not exempt another finding from decoy checks.
