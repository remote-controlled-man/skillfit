# Ground truth — explain-x1

`compactObject(obj)` (`src/compact.js`) returns a new object with every `null`, `undefined`, or empty-string value removed; `countDropped(obj)` reports how many keys that removes. Falsy-but-meaningful values (`0`, `false`) are kept, and the input is never mutated. `tests/compact.test.js` covers the removal rule, falsy retention, and input purity.

## Negative trigger control

This task is the bench's negative trigger control (`shouldTrigger: false` in `bench.json`). It is an explanation task, not a review task: there is no `CHANGES.diff` and there are no seeded defects. A code-review skill that fires on this task counts as a false trigger in L1 trigger-quality measurement.
