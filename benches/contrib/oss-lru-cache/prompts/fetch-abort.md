A pending `fetch()` may resolve to `undefined` or a bogus provider value when its background cache entry is evicted, deleted or replaced. If the provider never settles, the caller can remain stuck even though its abort signal has fired.

Repair cancellation semantics in the supplied lru-cache implementation: the caller should promptly reject with the cancellation reason, without waiting for the provider to finish. A late completion must not overwrite an explicit replacement or reinsert a removed entry. Preserve concurrent fetch deduplication, ordinary successful fetches and the existing stale-on-rejection option. Add a new executable `*.test.mjs` regression that fails on the original implementation and passes after the fix. Existing tests, runtime adapter, metadata and licenses must remain unchanged. Use only the local sources and Node built-ins; do not fetch a newer implementation.
