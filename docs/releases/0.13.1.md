# skillfit 0.13.1

This patch corrects the stale driver Skill and first-run commands that still
selected 0.12.0 in the published 0.13.0 package. Current pinned examples and
release links now use 0.13.1. Feature minimums retain their original versions;
the [0.13.0 release and evidence](0.13.0.md) remain unchanged.

The driver now explains explicit historical archive restoration, and the
first-run guide describes the existing `--compete-installed` option accurately:
it includes other user-level Skills from matrix directories, excluding system
Skills and plugins outside those directories. The roadmap points to the current
release record. No runtime behavior, statistical policy or evaluation evidence
changes in this patch.

## Release checks

The shipped [document check](release-docs-smoke.mjs) validates current package
commands in both READMEs, the driver Skill, first-run guide and archive guide.
Source release preparation and the actual extracted-package test run the same
check. A stale fixed command in any of those files, or an old README release
link, blocks validation. Historical feature minimums and frozen records are
outside this current-command check.

```bash
node docs/releases/release-docs-smoke.mjs /absolute/path/to/node_modules/skillfit
node docs/releases/0.13.1-feature-smoke.mjs /absolute/path/to/node_modules/skillfit /tmp/skillfit-0.13.1-feature-smoke
node docs/releases/archive-delivery-smoke.mjs /absolute/path/to/node_modules/skillfit /absolute/path/to/verified-archive-workspace /tmp/skillfit-0.13.1-archive-smoke
```

The new version-specific recipe retains the seven foundations groups, five moved
portable replays, 29 packaged regressions and temporary configuration/bundle
checks, adding installed-document digests and pinned-reference counts. Old
recipes are immutable. All smoke executors are synthetic; no real model/Agent
CLI calls or actual user configuration writes are part of these checks.

## Publication status

This preparation record is included in the immutable archive. It does not by
itself establish npm availability. The [release plan](../plans/2026-10-21-npm-0.13.1-release.md)
tracks review, source CI, the OIDC preview, one publication and independent
registry installation/document/archive verification. Final repository receipts
will be appended after publication; the accepted archive will not be replaced.

The CLI and restore tool require Node >=22. Historical frozen replay recipes
retain their original Node 24.21.0/TypeScript/POSIX requirements. Package
availability or replay consistency does not establish new Skill efficacy or
automatic upgrade permission.

## Preparation verification

The [local preparation receipt](0.13.1-preparation.json) records 882/882 offline
tests, zero failures/skips, five current documents with 19 matching command
references, the installed feature checks and offline restoration of all 19
archives plus 1,583 support files. The actual local candidate was 2,847,932 bytes
compressed, 18,499,259 bytes unpacked, with all 2,661 installed files compared.
These measurements precede final preparation records and are not registry sizes.

The [initial preparation failure](0.13.1-preparation-failure-1.json) is retained:
the new document CLI did not recognize an aliased temporary directory as its
entrypoint, so the actual-package test rejected empty output. Canonical entry
detection and a directory-alias regression fixed it; assertions were retained
and the complete suite passed. No publication occurred during preparation.
