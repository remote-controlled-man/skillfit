# skillfit 0.12.0

This release combines the new-user workflow fixes in
[PR #39](https://github.com/remote-controlled-man/skillfit/pull/39) and the case-authoring
fixes in [PR #40](https://github.com/remote-controlled-man/skillfit/pull/40).
Publication uses the existing [manual OIDC procedure](trusted-publishing.md).
This preparation record does not itself establish npm availability; verified publication
receipts will be recorded below after the accepted archive is available.

## Preparation validation

- `npm test`: 835 offline tests passed, with no failures, cancellations or skips.
- Contributed bench checks, changed documentation links, matching English/Chinese
  README code blocks and driver Skill validation passed.
- The local extracted archive passed the pinned seven-group foundations recipe,
  five moved portable replays, 29 packaged regressions and separate installed CLI
  stream success/failure probes. All executors and HTTP responses were synthetic;
  real model/API/Agent CLI invocations added: **0**.
- An initial local installed-only recipe selected a source-architecture assertion
  that requires intentionally unshipped TypeScript. That assertion remains in the
  full source suite; the corrected installed recipe verifies the actual stream
  runtime directly. The failed local archive/logs remain separate from the new
  successful attempt; no publication was attempted by either local check.

## Included behavior

- Git-root benches have matching content fingerprints and input snapshots. Invalid
  output locations, including directory aliases, fail during preview and setup.
- Ordinary CLI eval and judge calls retain structured token/cache usage separately
  from trigger detection. Known unsupported strict budgets block before calls.
- API answer-format/HTTP failures retain reported counters and public response
  evidence. Missing usage remains unknown; no historical costs are backfilled.
- Read-only bench commands, eval and calibration share bundled/local resolution.
  npm-first instructions and the driver Skill describe the installed workflow.
- Frozen cases never fall back from an empty/broken Git index. Non-Git imports
  require explicit `--include`; selected links and destination-bench files fail.
  Imports are bounded at 200 files / 1 MiB; narrow larger fixtures before importing.
- `--decompose` confirms before its single call and supports budgets, deadlines and
  fresh record groups. Inputs, public outputs, costs and failed/interrupted gates
  remain available. Concurrent bench edits are preserved; there is no automatic retry.
- Optional `verifierTimeoutSeconds` (integer 1–3600, default 120) applies to each
  verifier/oracle process in checks, eval, calibration, trigger mode and replay.

## Compatibility and limits

Non-Git `--freeze` now requires explicit `--include` selections. This intentional
restriction prevents silently capturing arbitrary local files. Tracked secrets or
files deliberately included outside Git still need review before sharing.
Existing cases retain their 120-second check limit unless configured otherwise.

Spending limits are observed stop lines; a single in-flight call may overshoot.
Missing provider usage cannot be reconstructed. Offline preflight does not prove
login or installed CLI flag compatibility. Statistical and adoption policy is
unchanged. This release adds no real Skill efficacy observations, model calls,
runtime dependencies or automatic upgrade permission.

## Reproduce installed checks

```bash
node docs/releases/0.12.0-feature-smoke.mjs /absolute/path/to/node_modules/skillfit /tmp/skillfit-0.12.0-feature-smoke
```

The recipe pins and derives the unchanged 0.11.0 foundations recipe for 0.12.0,
then runs the packaged offline regressions for the new fixes. It uses injected
executors, fake HTTP and synthetic fixture programs; it never evaluates a real
model or Agent CLI. Use a fresh output directory and preserve failed attempts.
The immutable npm archive contains this preparation record; repository records
can later append registry verification for that same accepted archive.
