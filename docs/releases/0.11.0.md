# skillfit 0.11.0

This version completes the basic case → plan → run/stop → report → portable
replay workflow. Registry publication and isolated-install verification are
pending; this source record alone does not establish package availability.

## Included behavior

- Hard case/environment failures stop calibration before any Agent invocation.
  Warnings and offline unknowns remain explicit.
- Paired, trigger and calibration runs expose bounded machine-readable previews,
  reviewed confirmation, task selection, deadlines and spending stop lines.
- Standalone checks and offline native/portable replay clean up verifier/oracle
  process trees on SIGINT/SIGTERM. Original saved runs remain unchanged.
- Independent judge receipts preserve successful, failed and interrupted usage;
  reports separate primary/judge/combined costs. Shared budgets count all roles.
- Native and portable single-arm evidence is audited without claiming paired
  efficacy. Historical missing costs/runtime support stay unknown or explicitly
  unsupported; no old receipts are rewritten.

The release also includes the shared planning, quoted-command/verifier-error,
single-arm report and offline Agent preflight work merged after npm 0.10.1.
See the [changelog](../../CHANGELOG.md), [planning guide](../eval-planning.md),
[cost contract](../eval-costs.md) and [portable package contract](../replay-packages.md).

## Verification and boundaries

- `npm test`: 794 offline tests passed, with no failures or skipped tests.
- Bundled code-review/debugging and contributed bench checks passed offline.
- README code blocks match in both languages; local documentation/schema links
  and the bundled driver Skill were checked.
- The [offline installed-feature recipe](0.11.0-feature-smoke.mjs) passed on the
  extracted local archive, with seven feature groups, five moved replay packages,
  eight synthetic invocations and zero network/model/Agent CLI calls. This does
  not yet verify a registry installation.
- Three-platform remote CI, exact release archive, registry integrity/provenance
  and an isolated installed-feature check remain delivery gates.

All implementation validation uses injected executors, fake HTTP and local
fixtures. Real model/Agent evaluation calls added: **0**. The statistical and
adoption policy is unchanged; evidence cannot automatically install or upgrade a
Skill. Offline environment checks cannot establish working authentication or
installed-version CLI flag compatibility.

Follow the existing [manual trusted-publishing procedure](trusted-publishing.md).
Publish once after its preview passes. An accepted upload followed by a registry
scan timeout is preserved and checked read-only, never uploaded again.
