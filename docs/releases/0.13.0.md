# skillfit 0.13.0

This release separates installation file transactions and makes historical
archive downloads explicit. The implementation was reviewed in
[PR #45](https://github.com/remote-controlled-man/skillfit/pull/45).
Publication follows the existing [manual OIDC procedure](trusted-publishing.md).
This preparation record does not establish npm availability; publication and
independent verification receipts will be appended after registry checks.

## Included behavior

- Installation planning delegates file operations to a dedicated transaction
  module. First backups survive competing writes, and failed rollback/cleanup
  preserves recovery copies and the original errors. Existing CLI parameters,
  confirmation, previews and user configuration backup behavior remain.
- npm excludes exactly 19 historical compressed archives. Git originals and
  frozen replay support remain. A shipped catalog/restore tool retrieves
  fixed-commit bytes, checks size/SHA-256 and prepares a fresh historical
  workspace. Normal install/eval/CLI commands never download archives.
- Restoration supports zero-write previews, selected IDs, all archives and a
  fully offline local source. Existing outputs, package contents and source
  directories are protected from overwrite. See the
  [restore guide](../archive-delivery.md) and [inventory](../archive-inventory.md).

## Compatibility and installed verification

Existing historical recipes now need explicit restoration before extraction.
Version 0.12.0 and earlier keep their original npm contents and immutable recipes.
The CLI/restorer requires Node >=22. Frozen historical recipes retain their
original Node 24.21.0/TypeScript/POSIX requirements; no new Windows replay claim
is made. Statistical/adoption contracts and real Skill efficacy evidence remain
unchanged. Runtime dependencies, real model/API and Agent CLI calls added: **0**.

The new recipe preserves the pinned seven-group foundations checks, five moved
portable replays, 29 packaged regressions and synthetic stream probes from the
previous release. It also verifies temporary configuration previews, first
backups, idempotent reinstall and a moved bundle's preview/install/reinstall.
All configuration writes use isolated temporary homes.

```bash
node docs/releases/0.13.0-feature-smoke.mjs /absolute/path/to/node_modules/skillfit /tmp/skillfit-0.13.0-feature-smoke
node docs/releases/archive-delivery-smoke.mjs /absolute/path/to/node_modules/skillfit /absolute/path/to/verified-archive-workspace /tmp/skillfit-0.13.0-archive-smoke
```

Choose fresh output directories and preserve failed attempts. The independent
archive check restores and verifies 19 archives plus 1,583 support files, refuses
existing destinations and proves preview purity and zero network use. It does
not establish registry availability. The
[release plan](../plans/2026-10-21-npm-0.13.0-release.md) tracks preparation,
review, publication and actual verification results separately.
