# skillfit 0.10.1

Prepared for the existing [manual OIDC publication procedure](trusted-publishing.md).
Publication is pending; npm 0.10.0 remains the verified published release until
the registry and installed archive checks succeed. This record will retain the
actual source, workflow and installation receipts after publication.

## Delivered workflow

- Read explicit chat-completions cached-input counts into retained costs and
  spending checks. Zero stays zero; absent or invalid cache evidence stays unknown.
- Open a manifest, native run directory or portable package in either Markdown
  or JSON. Both audit the same saved evidence and show acceptance reasons.
  Stopped/incomplete runs retain spending without becoming completed comparisons.
- Include Ctrl+C/SIGTERM cleanup and stopped-record sealing, mandatory offline
  case checks before live eval, and input snapshots sealed before dispatch.
  Export/replay survives original-input edits, deletion and moved run directories.

See [report inputs](../evaluation-reports.md), [cost accounting](../eval-costs.md),
[interruption](../evaluation-interruption.md), [case preflight](../eval-case-preflight.md)
and [input snapshots](../evaluation-input-snapshots.md). This release changes CLI
reliability and reproducibility, not the statistical or adoption policy. No real
model evaluations or agent CLI calls are added; historical evidence stays unchanged.

## Reproduce the installed-feature checks

The [offline recipe](0.10.1-feature-smoke.mjs) accepts an extracted or isolated
registry-installed package and a fresh output parent:

```bash
node docs/releases/0.10.1-feature-smoke.mjs /absolute/path/to/node_modules/skillfit /tmp/skillfit-0.10.1-feature-smoke
```

It checks the case workflow, API cache parsing with fake fetch, shared human/JSON
reports, stopped costs, input sealing and moved-package replay after originals
are removed. Only injected synthetic executors and fake API responses are used.
It retains `feature-smoke.json` and cleans its generated project/run data. No
Skill efficacy or token-cost reduction claim follows from implementation checks.
