# skillfit 0.10.0

The user authorized this case-workflow release on October 16, 2026. Publication
is pending until the exact archive is available from npm and an isolated registry
installation is verified. Source readiness or an upload alone is not completion.

## Delivered workflow

- Create a reply or code-editing starter, freeze a real failure or mine a fix.
- Inspect offline gate results with `bench check --json`.
- List/show cases and preview manifest edits/removals; apply with backup and
  validation. Removal keeps files and schema 1 remains nonempty.
- Select cases with repeatable `eval --task` or JSON request `taskIds`. Freeze IDs,
  order and full bench hash, preview only selected calls, retain all actual costs.
- Export paired native runs without a judge to a fresh portable directory with
  pinned inputs/implementation, original receipts, checksums and offline replay.
  Missing inputs reject export; stopped/partial evidence cannot become complete.
- Include optional whole-batch request spending guards introduced after 0.9.1.

See [case management](../case-management.md), [portable packages](../replay-packages.md),
[JSON bench checks](../bench-check-json.md) and the [component contract](../eval-component.md).
Exported project data requires review before sharing; exports stay local. External
verifier toolchains are the recipient's responsibility. Checksums detect changes,
not publisher identity. Legacy/redacted evidence retains its own dated recipes.

## Validation and publication

Offline tests cover selected budgets/order, invalid selections before calls,
case plans/backups/rollback, JSON output, preserved shared files, restored pinned
inputs, portable replay after originals are removed and stopped-cost retention.
Linux/macOS/Windows CI and bundled/contributed bench integrity must pass before
merge. The [manual OIDC procedure](trusted-publishing.md) prepares the exact archive,
previews it, publishes once, then verifies registry version/latest/integrity and
every installed file. Retain failed attempts if npm review delays availability;
verify the accepted archive read-only instead of uploading it again.

This is CLI usability and reproducibility work. Tests inject offline executors;
no real model or agent evaluation is authorized or added. The study remains at
195 recorded calls with seven historical final usages unknown. No Skill efficacy
claim, statistical-policy change, runtime dependency or automatic upgrade is included.
