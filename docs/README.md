# Documentation

Use the CLI help for flags; these guides explain workflows and contracts.
Current source includes unpublished changes beyond npm 0.13.1. A package version
string alone does not identify which source features are installed.

| Task | Guide |
| --- | --- |
| Install and run a first bounded evaluation | [First evaluation](guides/first-real-eval.md) |
| Build, import, check and manage cases | [Bench authoring](guides/bench-authoring.md) |
| Declare quality, efficiency or activation scope | [Bench claims](reference/bench-claims.md) |
| Exercise known benefit/harm/null/error controls offline | [Bench self-test](guides/bench-self-test.md) |
| Plan and run; inspect prerequisites and handle stops | [Evaluation workflow](guides/experiment-workflow.md) |
| Integrate machine requests, results and JSON schemas | [Component contract](reference/eval-component.md) |
| Interpret statistical verdicts and adoption limits | [Metrics](reference/metrics.md) |
| Read costs, share reports and replay sealed results | [Reports and replay](reference/evaluation-reports.md) |
| Compare rules and MCP configurations | [Configuration experiments](guides/config-experiments.md) |
| Select Skills or move a personal configuration | [Codex configuration](guides/selectable-codex.md) |
| Restore original evidence or find historical records | [Archives](maintainers/archive-delivery.md) |
| Develop, understand module ownership or prepare a release | [Architecture and maintenance](maintainers/architecture.md) |

[Current work](https://github.com/remote-controlled-man/skillfit/blob/main/docs/work/current.md)
contains unfinished work and a short status block. [Evidence](../evidence/README.md)
links dated results. [Release procedure](maintainers/releases.md) links original publication records.
JSON schemas, runnable examples and text-free/translated SVG assets remain in
`schemas/`, `examples/` and `assets/`. They are machine contracts and fixtures.

New behavior belongs in an existing task guide or its independent contract.
Completed plans, old release receipts, audits and frozen source copies are read
from their fixed Git snapshots; they are not maintained copies in this tree.

Previous source documentation: [fixed snapshot](https://github.com/remote-controlled-man/skillfit/blob/3a3ff415ccef1a3a45d1e2d2cc00d903ab7db850/docs/README.md).
